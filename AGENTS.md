# michaelbritten.music working agreement

This is a static preservation of the site formerly rendered by Super from Notion.

- Keep the site build-free and GitHub Pages compatible unless Michael explicitly requests an architectural change.
- Preserve the current visual design and responsive behavior unless Michael explicitly requests a redesign or correction. Some narrow mobile layouts wrap awkwardly; that is part of the captured design.
- Keep site-owned fonts, images, audio, icons, and PDFs local under `assets/`. Do not reintroduce runtime dependencies on Super or Notion.
- The Tally contact form and YouTube video remain external because they provide live embedded functionality.
- Before claiming a visual change is complete, serve the repository locally and inspect both a 1280px desktop viewport and a 390px mobile viewport.
- Publishing, custom-domain configuration, Cloudflare DNS changes, and Super cancellation are a separate migration phase.
